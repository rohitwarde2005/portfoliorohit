# Rohit S Warde — Portfolio Website

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive design, animations and dark mode styles
- `script.js` — mobile menu, dark mode and scroll reveal animations

## How to run
1. Keep all three files in the same folder.
2. Open `index.html` in a browser.

## Customization
- Update text/content in `index.html`.
- Change colors, spacing and typography in `style.css`.
- Add GitHub project links inside the project card when available.
- Replace the `RS` avatar with a professional profile photo if desired.

The site is responsive and works on desktop, tablet and mobile.
